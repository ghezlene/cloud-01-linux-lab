> Learn Linux by operating, configuring, automating, and troubleshooting real systems.

## Overview

Linux is one of the fundamental technologies behind modern servers, cloud infrastructure, containers, and DevOps environments.

This project explores Linux system administration through practical exercises and automation scripts.

The objective is not simply to memorize commands, but to understand how a Linux system works and how to operate it.

## Learning Objectives

- Understand the Linux filesystem hierarchy.
- Navigate and manipulate files through the terminal.
- Manage users, groups, ownership, and permissions.
- Understand processes and system resources.
- Install and manage software packages.
- Configure and troubleshoot system services.
- Understand SSH and remote server administration.
- Write Bash scripts to automate repetitive operations.
- Inspect logs and diagnose common system problems.

## Practical Labs

| Lab             | Description                                        |
| --------------- | -------------------------------------------------- |
| Filesystem      | Explore directories, files, links, and disk usage  |
| User Management | Create users, groups, and permissions              |
| Processes       | Inspect, manage, and terminate processes           |
| Services        | Configure and manage systemd services              |
| SSH             | Configure secure remote access                     |
| Storage         | Inspect disks, partitions, and mounted filesystems |
| Logs            | Investigate system and application logs            |
| Automation      | Create reusable Bash scripts                       |

## Automation Projects

Planned scripts include:

- System information collector.
- Disk usage monitor.
- Automated backup script.
- User management helper.
- Service health checker.
- Log inspection utility.
